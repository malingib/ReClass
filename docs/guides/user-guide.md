# ReClass — User Guide (Teacher & Parent)

## Teacher
**Login:** open the portal link → enter email + password (MFA if required) → land on your timetable.
**Mark attendance:**
1. Go to *Timetable* → tap today's session (or use the mobile FAB "Mark").
2. Roster opens pre-filled. Tap **Mark all present**, then change individuals (present/late/absent/excused).
3. Save. If offline, marks queue and send when you reconnect.
4. Once the principal approves (or 24h passes), attendance locks — edits then need a reason.
**Upload notes:** *Notes* → choose group → upload PDF/photo (stored in Supabase Storage).
**See students:** *Students* shows only your assigned groups.

## Parent
**Get started:** admin sends an invite (SMS/email) → set password → login.
**View:** *Attendance* (per child), *Timetable*, *Fees* (outstanding), *Announcements*.
**Pay fees:** on *Fees*, tap **Pay now** next to an invoice → enter your M-Pesa phone → confirm the STK push on your phone → done. You'll get an SMS confirmation; the ledger updates live.
**Language:** toggle EN/SW top-right.
**SMS:** you'll get an SMS if your child is absent (reply STOP to opt out). Pay links arrive by SMS too.

## Accessibility
Dark mode follows your system. All actions are keyboard reachable. Text contrast meets WCAG AA.
