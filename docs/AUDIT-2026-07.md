## PHASE 2 — Architecture

RBAC roles: school_admin, super_admin, teacher, parent, principal, bursar. Two-step nav (role on /, module under role prefix). Route group (app) wraps authenticated routes.

Middleware chain: validateEnv (startup) -> initClients -> correlationId -> resolveSession -> handleImpersonation -> securityHeaders -> routeGuard -> resolve.

## PHASE 5 — Security

| Finding | Severity | Detail |
|---|---|---|
| Service-role RLS bypass, honestly documented | Medium | locals.srv bypasses RLS; isolation via .eq('tenant_id'). Migration header states it's defense-in-depth — honest, NOT dead-code trap. App-code discipline is single point of failure. |
| Tenant scoping | Pass | Manual audit confirms every read/update/delete has .eq('tenant_id'). Scanner's 43 leaks are false positives (filter past 400-char window). |
| M-Pesa callback auth | Strong | Fail-closed on missing secret; constant header check; body-size cap; reads tenant_id from DB row not body; idempotent (status guard + ON CONFLICT); server-derived amount |
| reconcile_payment RPC | Strong | SECURITY DEFINER, SET search_path, FOR UPDATE lock, re-asserts p_tenant_id, records overpayment; REVOKE anon/authenticated, GRANT service_role only |
| Credential encryption | Strong | Vault KEK + pgp_sym_decrypt; tenant/role check before decrypt; Edge-only |
| Rate limiting | High (at scale) | In-memory Map; resets on cold start, not shared across instances — ineffective on Vercel. Needs distributed store. |
| Secret leakage in logs | Good | notify scrubs Bearer/api_token |
| Security headers | Good | HSTS, nosniff, X-Frame, Referrer-Policy. MISSING: CSP |
| STK duplicate guard | Good | Pre-insert checkout, 429 on concurrent pending |
| Impersonation | Good | HMAC cookie bound to client IP, super_admin only |

OWASP: injection/auth/access-control/crypto/secrets all pass. Gaps: no CSP, in-memory rate limit, no dependency scan.
